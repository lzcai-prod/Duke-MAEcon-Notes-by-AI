# AI-Econ-Notes

Notes generated by AI that I found useful. Each set includes a printable PDF, the raw LaTeX source, and the main prompts in Markdown. Created with Claude Opus 5.

They should be good enough for review if you are coming in without an econ background, and good enough to build on if you are a current or future student. Next year's models will be stronger, so treat these as a starting point to regenerate from, or as a benchmark to save yourself some tokens.

Some notes reference course materials I am not able to upload. Most of the content is based on standard textbooks that are available through other sources.
